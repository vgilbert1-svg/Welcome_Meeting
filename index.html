Fair play on the website

Work is locked when the rules are broken

  • Not following instructions locks the activity
  • Trying to use AI to do the work locks the activity
  • Students learn by doing the thinking themselves

This keeps assessment fair and shows us what each student can really do.

Unit spotlight · Databases

Organising data so it can be found

  • Designing tables, fields and records
  • Primary keys and foreign keys
  • Connecting tables so data is not repeated

Unit spotlight · Networks

Design your own network

  • Network hardware and types (PAN, LAN, WAN)
  • Bus, ring and star topologies
  • Protocols: TCP/IP and HTTP
  • Checking for errors with parity bits
  • Network security and machine learning

Unit spotlight · Coding and testing

Writing and testing real code

  • Text-based programs in MicroPython, run on physical devices
  • Loops, arrays and selection (IF)
  • Trace tables to find and fix errors
  • Test plans with normal, extreme and invalid data

Class expectations

What we ask of every student

Arrive ready

On time, with a notebook and pen, ready to start the starter task.

Keep good notes

Copy the key notes into the notebook. They are the best revision tool.

Respect the equipment

Computers and micro:bits are shared. Handle them with care.

Try first, then ask

Mistakes are part of coding. We test, find the bug and fix it.

Do your own work

No AI or copying. Breaking the rules locks the activity on our website.

Be kind and safe online

Respect others and protect personal information.
